Datenschutzhinweise anzeigen
  • Alle Angaben bleiben ausschließlich in diesem Browser auf diesem Gerät – kein Konto, keine Analyse, kein Tracking, keine Werbung.

  • Andere Geräte oder andere Browser sehen diese Daten nicht. Zum Übertragen nutze Export und Import.
  • GitHub Pages stellt nur die App bereit und schützt keine privaten Daten. Jede Person mit Zugriff auf dieses entsperrte Gerät und diesen Browser könnte die gespeicherten Einträge sehen.
  • „Mein Bereich“ und die gemeinsame Ansicht sind eine Rücksichtsfunktion, keine echte Zugriffskontrolle.
  • Die Sicherungsdatei (JSON) ist nicht verschlüsselt. Bewahre sie an einem sicheren Ort auf.

Namen der Profile

Sync zwischen euren Handys

Gleicht Einträge, Wunschliste, Lust-Signale und Einstellungen über ein privates GitHub-Repository ab. Alles wird vorher auf dem Handy mit eurem Sync-Passwort verschlüsselt (AES-256) – GitHub sieht nur unlesbare Daten.

Ohne dieses Passwort sind die Daten nicht lesbar – es kann nicht wiederhergestellt werden.

Push (ntfy)

Sendet das Lust-Signal als Push-Benachrichtigung aufs Handy der anderen Person – über euren Server ntfy.chaoten.online. Die andere Person abonniert dafür in der ntfy-App ihr Topic.

Sendet Person A ein Signal, geht der Push an das Topic von Person B – und umgekehrt.

Das Token wird nur in diesem Browser gespeichert – nicht im Backup-Export und nicht im (öffentlichen) GitHub-Code. Tipp: Ein Token, das nur in diese beiden Topics schreiben darf.

Selbstbefriedigung

Blendet im Formular die optionale Frage „Habe ich mich heute selbst befriedigt?“ ein – gleichberechtigt für euch beide. Die Angabe ist wie alle anderen in der gemeinsamen Ansicht sichtbar.

Zyklus

Blendet im Formular die optionale Frage zur Zyklusphase ein. In der Auswertung erscheint dann „Lust nach Zyklusphase“.

Sichern & Wiederherstellen

Exportiere alle Einträge als JSON-Datei, um sie zu sichern oder auf ein anderes Gerät zu übertragen.

Alle Daten löschen

Entfernt alle Einträge und Namen aus diesem Browser. Das kann nicht rückgängig gemacht werden.
